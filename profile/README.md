# OWASP dep-scan

dep-scan is an OWASP project that audits project dependencies and container images for security and risk, based on known vulnerabilities, advisories and license limitations. Read the [documentation](https://depscan.readthedocs.io) to get started.

```sh
pip install owasp-depscan
```

## Repositories

| Repository                                             | What it is                                                                                       |
| ------------------------------------------------------ | ------------------------------------------------------------------------------------------------ |
| [dep-scan](https://github.com/owasp-dep-scan/dep-scan) | The dependency scanner and risk audit tool                                                       |
| [blint](https://github.com/owasp-dep-scan/blint)       | Binary linter that checks executables' security properties and capabilities, and generates SBOMs |
| [dosai](https://github.com/owasp-dep-scan/dosai)       | Lists namespaces and methods from .NET sources and assemblies                                    |

## Getting involved

- Ask questions and share ideas in [Discussions](https://github.com/owasp-dep-scan/dep-scan/discussions).
- Read the [contributing guide](https://github.com/owasp-dep-scan/.github/blob/main/CONTRIBUTING.md) before opening a pull request.
- Report vulnerabilities privately, as described in each repository's security policy.

We build these projects with the help of AI coding agents and say so openly. Each repository has an AI-DECLARATION.md that describes how AI is used there, and pull requests made with AI carry an `ai-*` label for the level of AI involvement.
